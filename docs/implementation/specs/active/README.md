# Active Specs Folder Note

`active/` is not an instruction to execute every file in this folder.

It contains both current approved baselines and retained execution records whose
paths are stable audit evidence. Before acting, read the individual file status
and `docs/context/DOCUMENT_REGISTER.md`.

- A file marked `Approved Baseline` or `Approved with Open Decisions` may guide
  its documented scope, but still does not authorize unrelated implementation
  or unresolved decisions.
- A file marked `Implementation Merged` or `Implementation Completed` records
  prior work and remaining gates. Do not re-execute it or infer rollout,
  production-readiness, or go-live approval.

See [`../README.md`](../README.md) for the full lifecycle index.
