# Pending-Reconciliation Folder Note

`pending-reconciliation/` does not mean “ready to implement.” It retains plans
that need authority revalidation, evidence reconciliation, or separate
approval.

- Files marked `Pending Separate Implementation Approval` are proposals only.
- Files marked `Context Only`, `Partial`, `Implemented`, `Completed`, or
  `Resolved` are evidence records and must not be re-executed from their old
  checklists.
- If a task is still needed, start from the Master Spec, Document Register,
  Decision Register, relevant decision or ADR, and current source/tests. Create
  a new task card with fresh scope and authorization.

See [`../README.md`](../README.md) and the Document Register for the current
classification of each file.
