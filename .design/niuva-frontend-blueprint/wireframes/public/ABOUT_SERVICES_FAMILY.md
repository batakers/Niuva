# PUB-04 About and Four-Equal-Services Family Wireframe

**Status:** Candidate — Context Only — Public route-family artifact

**Routes:** `/tentang`, `/en/about`, `/layanan`, `/en/services`

## 1. Family model

About answers who Niuva is and how it approaches work. Services answers which
of four equal Services fits a need. They share Public navigation, typography,
evidence and Contact handoff, but do not become one repeated card template.

```text
About: identity/partner role → factual dossier/evidence → approach → values/ecosystem → next action
Services: equal overview → four equal detail actions → recovery → Contact handoff
```

The four Services retain equal information and visual rank:
Research & Development; Consultant & Workshop; Design & Prototyping; Apparel &
Merchandise.

## 2. States and content truth

| State | Visible contract | Boundary |
| --- | --- | --- |
| Ready | Factual identity, approach, four equal Services, owned next action | No invented history/team/capacity |
| Loading | Stable heading/evidence hierarchy | No content/status inference |
| Missing evidence | Text-led placeholder or omitted claim | No stock/generated project proof |
| Translation unavailable | Approved Indonesian fallback notice | `noindex,follow`, Indonesian canonical |
| Dependency error | Visible error and bounded retry/fallback | No fabricated content success |
| Empty/unknown detail | Honest unavailable state | No reserved project detail activation |

## 3. Responsive/accessibility

Use 320/390/768/1024/1440 reasoning, 65–70ch prose, 16px mobile body, 44px
targets, semantic headings/landmarks, 200% reflow, visible focus, ID/EN long
copy, and static reduced-motion content. Four Services may stack or alternate;
none is demoted by layout order or disclosure.
