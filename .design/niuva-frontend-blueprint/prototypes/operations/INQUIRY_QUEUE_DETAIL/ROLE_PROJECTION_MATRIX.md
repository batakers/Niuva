# OPS-01 Inquiry Role Projection Matrix

| Context | Visible | Not visible | Recovery |
| --- | --- | --- | --- |
| Queue ready | Scope, query, factual count/cursor, identity/status/age | Unrelated queue resources and broad audit data | Open authorized detail or reset filter |
| Detail ready | Inquiry reference, safe contact/need, lifecycle status, history | Internal secrets, unrelated customer data | Return to queue with safe context |
| Permission failure | Safe forbidden message | Which hidden records exist | Request authorized help or return |
| Conflict/uncertain | Changed version/unknown outcome | False mutation success | Reconcile before retry |
| Success | Persisted action and existing Inquiry reference | Conversion/Quote/Project inferred from UI | Continue manual Operations triage |

**Self-review:** Role scope and lifecycle ownership remain separate from route
visibility and visual hierarchy.
