# PUB-02 Public Art Direction B — Workshop Index

**Status:** Candidate — Context Only — held alternative for comparison; not
runtime source, token promotion, or final art-direction approval

**Baseline:** `8555685c29a3fde9976ae6499336e2eb45a330ba`

## 1. Intent

Direction B treats the Homepage as an open workshop index: a mineral canvas,
larger typographic labels, visible annotations around factual evidence, and
short “what this proves” captions. It is more expressive than Direction A but
keeps the same information order and lifecycle boundaries.

## 2. Composition

```text
quiet canvas
  HERO: proposition aligned to a measured left rail
  JOURNEY CHOICE: two large text actions, no pill-card grid
  PROCESS: five stages separated by whitespace and one semantic connector
  PROJECT INDEX: alternating media/caption rows, not a carousel requirement
  SERVICES: four equal chapters on a shared baseline with different copy lengths
  RETAIL: specification-led secondary entry
  CONTACT/FAQ/CLOSING: direct task surfaces with no workshop metaphor in state copy
```

The annotation language is content-led. It cannot claim a method, client,
outcome, or test unless the evidence record supports that exact claim.

## 3. Typography, material, and LOCAL values

- Mona Sans Variable carries the entire durable hierarchy.
- One optional Bona Nova interruption may punctuate Public copy; no repeated
  italic labels or tiny uppercase eyebrows.
- Local offsets, annotation strokes, crop ratios, and mineral/paper values stay
  inside this study. They do not become global or Public tokens.
- Evidence rows can use deep ink as a factual-media field; ordinary Services,
  Contact, Account, and Operations panels remain flat-first.

## 4. Bounded interaction and motion

- Annotation appears only when it explains a factual caption or media state.
- Project media does not delay its caption or action.
- Hover changes affordance without hiding content or shifting layout.
- A 120/180/280ms grammar is sufficient; longer choreography requires a
  separately evidenced Public experiment.
- Reduced motion removes spatial movement and leaves the complete static index.

## 5. Anti-template review

| Check | Result |
| --- | --- |
| First-order | Public/B2B/Retail choice and four equal Services remain clear. |
| Second-order | Workshop cues are local expression, not a second lifecycle or process rail. |
| Logo-hidden | Copy hierarchy still identifies a precise evidence-led studio. |
| Repeated-card | No transferable card grid; alternating rows are a local composition. |
| Lines/metrics | No ornamental rule field, telemetry, or fabricated score. |
| Surface fit | Workshop expression stops at Public; Retail/Auth/Admin stay task-first. |
| Truth | Conceptual or stock support is labelled and never project evidence. |

## 6. Self-review and disposition

Self-review passed against PUB-01 and the token/component/state contracts.
Direction B is **held as an alternative**: it adds more annotation and media
composition risk than Direction A, so it should not proceed to source without
owner selection and evidence review. It remains available for comparison and
is intentionally not deleted as historical design evidence.
