# PUB-02 Public Art Direction A — Evidence Ledger

**Status:** Candidate — Context Only — preferred calibration direction; not
runtime source, token promotion, or final art-direction approval

**Baseline:** `8555685c29a3fde9976ae6499336e2eb45a330ba`

## 1. Intent

Direction A treats the Homepage as an editorial evidence ledger: generous
paper field, selective Niuva blue, deep evidence surfaces only where factual
project media needs contrast, and typography/content carrying most of the
identity. It keeps the PUB-01 hierarchy and avoids a transferable agency
template.

## 2. Composition

```text
paper canvas
  HERO: one clear proposition + two journey choices
  └─ editorial gap, no decorative divider
  DUA CARA MEMULAI: B2B-primary / Retail-secondary, asymmetric but equal clarity
  CARA KERJA: one five-stage semantic rail, static-complete
  EVIDENCE FIELD: dark material surface only for verified project proof
  FOUR SERVICES: staggered text/space arrangement, no 2×2 card parade
  RETAIL / CONTACT / FAQ: lighter task transitions
  CLOSING: quiet full-bleed paper action, no replacement contour
```

The deep evidence field is an expression of factual media, not a dashboard,
telemetry panel, or status surface. If an approved image is unavailable, the
field becomes a text-led placeholder and does not pretend to show a project.

## 3. Typography, material, and LOCAL values

- Mona Sans Variable remains display/body/UI.
- Bona Nova Italic may appear once as a short Public interruption; it is not
  used for navigation, form labels, status, or long copy.
- System monospace is reserved for genuine identifiers and measurements.
- Durable tokens supply text, surface, focus, border, spacing, radius, and
  motion roles. Any paper tint, evidence-field treatment, crop, or editorial
  offset remains LOCAL to this study.
- No gradient, glass, neon, fake metric, decorative section number, or generic
  shadow is required. Shadow is limited to navigation/overlay depth.

## 4. Bounded interaction and motion

| Moment | Normal behavior | Reduced behavior |
| --- | --- | --- |
| Hero arrival | Short opacity/position choreography only after content exists | Static content immediately visible |
| Process rail | One semantic connector cue, no progress meaning | Static ordered stages |
| Evidence media | Caption/action remains available before or beside media reveal | Static media/caption |
| Contact/FAQ | 120–180ms disclosure or feedback | Direct state change |
| Closing | No scroll hijack or autoplay | Static closing action |

No new runtime dependency is implied. CSS is the default; any existing GSAP
use would require an exact-file source gate later.

## 5. Anti-template review

| Check | Result |
| --- | --- |
| First-order | Niuva's four Services, B2B path, evidence contract, and process are visible. |
| Second-order | Contrast changes follow evidence/task meaning, not generic card variation. |
| Logo-hidden | The hierarchy still reads as a precise product studio rather than a SaaS landing page. |
| Repeated-card | Rejected; Services and evidence use editorial blocks and captions. |
| Decorative line/number | Rejected except semantic process connector. |
| Bento/grid | Rejected for Public; reserved for a separately proven Operations need. |
| Truth | No invented project asset, client, metric, status, or production claim. |

## 6. Self-review and disposition

Self-review passed against PUB-01, DS-02 through DS-05, `DESIGN_TOKENS.md`, and
Public authority. Direction A is **preferred for further calibration** because
it preserves the strongest evidence-led hierarchy with the fewest new visual
assumptions. Preference is not owner approval or source authorization.

Open evidence: real project assets, factual captions, browser contrast, and
responsive screenshots still require the later QA task. Direction B remains a
valid alternative and is not deleted.
