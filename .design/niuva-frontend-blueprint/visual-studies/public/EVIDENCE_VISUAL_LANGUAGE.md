# EXP-03 Evidence and Supporting-Visual Language

**Status:** Candidate — Context Only — provenance/presentation language; no
asset rights, CMS schema, migration, or source change

## 1. Two visual classes

### Project/product evidence

Only a real, approved asset may substantiate Niuva work. The owner records an
evidence ID, related record, controlled asset path/source, rights basis, factual
review owner, evidence type, exact supported claim, caption, alt text,
derivative/crop disclosure, checksum/revision, ID/EN readiness, and last review
date.

### Supporting/explanatory visual

Conceptual, stock, or generated imagery may explain a concept only when rights
and workflow permit it and the label is honest. It cannot substantiate a Niuva
project, client, method, capability, output, outcome, status, or production
claim.

## 2. Presentation rules

- Caption and factual claim remain visible; hover cannot be the only source.
- Crop/edit/derivative changes are disclosed where relevant.
- Missing media uses a text-led fallback:

  > Dokumentasi visual untuk tahap ini belum tersedia. Ringkasan berikut hanya
  > memuat fakta project yang telah diverifikasi.

- If the underlying claim is unverified, omit it and record the content gap.
- Gallery/collection keyboard action, loading, empty, unavailable, dependency
  error, and reduced-motion states remain complete without media animation.
- A final-object photo does not automatically prove research, testing, or
  process; the source must support the exact claim.

## 3. Sample provenance record

| Field | Example placeholder | Review rule |
| --- | --- | --- |
| Evidence ID | `EVIDENCE-REVIEW-001` | Replace only with owner-assigned ID |
| Asset/source | `[controlled path or source]` | No invented path or rights |
| Type | project photo / process / final object / test | Choose factual type |
| Claim | `[exact verified claim]` | Omit if not supported |
| Caption/alt | `[ID]` / `[EN]` | Visible, descriptive, non-inflated |
| Rights/revision | `[basis]` / `[checksum]` | Review before publication |
